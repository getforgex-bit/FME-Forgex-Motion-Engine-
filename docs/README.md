# Documentación de FME

## Convenciones de certeza

Heredadas de la especificación (§ "Convenciones y nivel de certeza"). Úsalas en toda la documentación, en los ADR y en la bitácora:

| Etiqueta | Significado |
|---|---|
| **ACORDADO** | Definición de producto o preferencia expresada y aceptada |
| **PROPUESTO** | Recomendación de implementación aún no aprobada mediante prueba |
| **POR VALIDAR** | Compatibilidad, rendimiento, licencia o automatización no demostrada |
| **FUERA DEL ALCANCE ACTUAL** | Ideas posteriores al cierre; solo se dejan interfaces de extensión |
| **VERIFICADO** | Probado con un comando o artefacto reproducible (citar en la bitácora) |

Un repositorio público no implica compatibilidad inmediata con FME, API estable, derechos sobre todos sus recursos ni soporte comercial de sus dependencias.
