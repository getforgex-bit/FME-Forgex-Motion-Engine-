# Bitácora de trabajo

Una entrada por sesión o hito relevante: `AAAA-MM-DD-<id-sesion>-tema.md` (con varias sesiones; plantilla: [`_plantilla.md`](_plantilla.md)).

Sirve para el **relevo** entre personas y agentes: quien retome el trabajo lee la última entrada, comprueba el estado real (`git log`, `git status`, `npm run typecheck`) y continúa. Se transfieren resúmenes verificables, no conversaciones.
